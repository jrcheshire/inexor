One-node N-body: a memory-floor design study

Goal: gravity-only PM-class N-body that maximizes particles per one GPU or one node, with memory as the objective and compute freely tradeable (2–3× is fine). Science lane: large-volume quasi-linear mocks — P(k), bispectrum, fNL. Differentiability is an optional overlay, not the headline. Sources: the inexor/mbody measured record, two fresh measurements run this session on stored trajectories, and an 8-agent literature sweep with primary-source verification.

TL;DR

inexor attacked the smallest term. Its own R6 profile says the memory enemy ordering in a JAX PM code is transients (~430 B/p adjoint, ~126 B/p forward) » mesh (~8–16 B/p per mesh:particle ratio) > state (12 B/p). CUBE runs production PM at 9.84 B/p all-in (particles + meshes + temporaries), so the ~14× gap between our measured JAX forward peak and the hand-managed floor is framework and design, not physics.

What I would do: run the one-week premise-gate battery (§7) first, then build A2 “Mock Factory” — a two-level-mesh PM (PMFAST/CUBE2 lineage) with CUBE-class compressed state, deterministic int paint, on-demand tile ICs, and custom paint/gather kernels — targeting 10–16 B/p all-in: 2048³ on one Vista GH node, 4096³ host-resident on one Stampede3 H100 node. A3 “Any-GPU tile factory” (sCOLA-style sequential tiles in plain JAX) is the low-effort companion if its seam/bispectrum gate passes — a statistic nobody in the tiling literature has ever measured. The differentiable sequel (A5) is real but waits for a named workflow, per the retrospective rule. Our 437–490 B/p adjoint measurements are the first quantified numbers in that literature either way.

Section 1

Lessons ledger — what the inexor arc actually taught

Refuted premises dead

  • “Float replay drifts”: DISCO-DJ f32 replay gradient error is ~4e-5 and flat in K (3.96/4.26/3.97/3.45e-5 at K=5/10/20/40). Nothing accumulates. The motivating number was a different code’s (pmwd), different quantity (state RMSD), never measured on the target.
  • “int16 state makes the adjoint fit”: adjoint peak is ~440–490 B/p for inexor and DISCO-DJ; carry is ~8% of peak; the 12 B/p saving is ~3%. Sec. 9’s transient estimate was off ~14×.
  • “O(1)-in-steps is a differentiator”: table stakes; pmwd and DISCO-DJ are O(1) too.
  • inexor’s int16 quantization error (2e-4..4.5e-3) is 5–100× larger than the f32 replay drift it was built to remove.

Validated assets keep

  • int16 forward state (12 B/p): quantization k-flat 1–3e-4 dP/P, below the PM mesh floor in every band (gate D-014).
  • Deterministic int32-mesh CIC paint: bit-stable on CUDA and 0.79–0.85× the f32 paint time. Reproducible mocks for free; keep it in every design.
  • Exact reversibility at scale: 512³ roundtrip n_diff=0 in 6.4 s on a GH200.
  • The instrument suite: floor-first gates (D-010..D-015), parity harness (mbody + DISCO-DJ arms), quant-gate, mem-profiler (one config per subprocess; sweep the discriminating axis).
  • Working aarch64/CUDA pixi envs on Vista + deneb; the whole ops runbook.

Process rules binding

  • Price the premise first. Every architecture below carries a cheap decisive measurement and a kill trigger; none gets built before its gate.
  • Never inherit a number across codes or quantities. Published figures are hypotheses about that code, that quantity, that config.
  • The transient sets the budget: compute saving / measured_peak before designing around any term.
  • Name the workflow before building a capability (the differentiable overlay waits for this).
  • Floors before gates; tolerances never relaxed silently; global metrics for noise-dominated per-particle quantities.

Citation guard never cite

  • “HACC 36 B/p” — that figure is PKDGRAV3’s 2LPT IC footnote; HACC publishes no B/p.
  • “CUBE2 ~20 B/p vs Gadget-2 ~80” — search-layer conflation (an AI search summary reproduced it verbatim this session; it is in neither primary text).
  • New this session: “HACC particle overloading ≈ 10% memory” is not in the primary papers (zone width 2–10 Mpc/h is; the percentage is folklore).
  • New: sCOLA’s “16 Gpc/8192³ = 19.8 TB → 53 MB/tile” projection did not re-verify on my fetch; use only the verified 1 Gpc numbers.
  • pmwd’s benchmark GPU is an H100 PCIe 80 GB (not A100).

New measurements this session (from stored M1 trajectories; no new sims)

Both runs use the existing 128³ K=40 (and 64³ K=10) f64 artifacts in runs/m1/; references rebuilt with inexor’s own lpt/cosmology (IC reproduction from the stored delta0 is exact, so conventions are verified in-run). Caveats: one seed, L=256 Mpc/h, one-shot quantization (codec applied once to the final state). D-014 measured the accumulated (quantize-every-step) int16 error at 2.8e-4 against 1.4e-5 one-shot here, so carry a ≈20× one-shot→accumulated multiplier until the real gate runs.

Cell-relative int8 is int16-grade at half the bytes, and its quantum (cell/256) does not degrade with mesh size, where the global-216 lattice drops to 32 sub-cell levels at n_mesh=2048. Pure residual coding fails: saturated heavy tails dominate (more bits do not help), so it needs a sparse outlier ledger to be viable at all. Velocity 8-bit codecs all fail on tails; CDF companding is worse than linear there. CUBE’s live velocity code works because its reference is the local coarse-grid mean flow (adaptive), not a static LPT prediction, and its fidelity bar (k ≤ 0.2 kNyq) is looser than D-014.

Section 4

Approach catalog

Source tags: [M] measured in-house · [V] primary source verified by me this session · [A] agent-verified against primary text · [!] asserted / not verified. Effort: S < 1 wk, M ~ 2–4 wk, L > 1 mo of sessions.

4.1 State codecs

S1 · int16 global lattice validated

12 B/p. D-014: error k-flat 1–3e-4, below the PM mesh floor everywhere. [M]

  • Pros: already built and gated; JAX-native static shapes; exact wrap.
  • Cons: quantum grows with L; sub-cell levels shrink with n_mesh (64 at 1024 → 16 at 4096); 2× the bytes of S2.

Gate: none needed. Effort: S (exists).

S2 · int8 cell-relative positions promising

3 B/p positions (+ velocity codec separately). One-shot measured at 3.1e-5 max dP/P — int16-grade. Quantum = cell/256 at any mesh size. CUBE lineage precedent in production. [M] [V]

  • Pros: halves position bytes at measured fidelity; removes the n_mesh ceiling; composes with tiles (cell = tile-local coordinate).
  • Cons: needs cell-bucketed storage (sorting/lists) — hostile to plain XLA (the D-004 rationale), natural in custom kernels; accumulation gate pending (~6e-4 projected vs the 5e-4 D-014 bar — may need cell/512).

Gate: plug into m1_quant_gate accumulated; kill if >2× over the mesh floor in any band. Effort: M.

S3 · CUBE x1v1 with local-flow velocity proven at F2

6 B/p total: int8 cell-relative positions + int8 velocity residual vs the coarse-grid mean flow, CDF-binned. Production-proven at 4.4 trillion particles (Cosmo-π, 95% weak scaling) at CUBE’s fidelity bar: error below PM error for k ≤ 0.2 kNyq. [V]

  • Pros: the 6 B/p floor with receipts; the local-flow reference adaptively absorbs bulk + virial motion (what killed our static-LPT version).
  • Cons: F2-grade, not D-014-grade — fine when the mesh is fine (cell ~1 Mpc/h puts 0.2 kNyq ~ 0.63 h/Mpc above the fNL k-range); velocity error feeds step-to-step accumulation that must be re-gated at our bar.

Gate: accumulated quant-gate at production config; kill if F1 unreachable at 6 B and 9 B (int16 vel) both fail cost checks. Effort: M.

S4 · LPT-residual frame (Lagrangian order) conditional

Store residuals vs a regenerable ZA/2LPT reference, q-indexed (identity = array index, no sorting). Measured this session: ~5× position range reduction but fatal 26σ tails without an outlier ledger (0.2–0.8% of components saturate any int8 range). [M]

  • Pros: JAX-friendly (static shapes, no bucketing); the frame is COLA’s (fewer steps come along); pairs with on-demand reference regeneration (R1). “Quantized COLA” is confirmed absent from the literature.
  • Cons: needs ledger machinery (~0.1–0.2 B/p sparse exceptions) to be correct; loses to S2 on measured fidelity-per-byte; velocity residuals barely compress.

Gate: ledger-corrected accumulated error vs S2 at equal bytes; kill if S2 wins (likely). Effort: M.

S5 · f16/bf16 state dead

Klöwer et al.: bf16 cannot integrate additive dynamics (tendencies swamped by state magnitude) — exactly the drift/kick failure mode fixed-point avoids by holding a uniform LSB. Do not revisit. [A]

S6 · Dithered (stochastic) rounding on int increments small, open

Croci–Giles: round-to-nearest stagnates small increments; SR removes the bias. Counter-keyed deterministic dither keeps replayability. Unpublished for fixed-point N-body. Only matters if a codec sits near its quantum; test inside whichever codec wins. [A]

Effort: S (a rounding-site swap + the R4-style gate rerun).

S7 · Entropy/offline packing for at-rest tiers safe add-on

pack9-style 12+12-bit cell-relative = 8.5 B/p on disk (AbacusSummit); GPZ reports 130–220× at 1e-3 bounds for outputs. Use for the host/NVMe streaming tier and snapshots, never as the working GPU representation (random access). [A]

4.2 References & initial conditions

R1 · On-demand tile ICs / references promising

White noise from a counter-based hash keyed on the absolute q-cell (JAX Philox/Threefry is native), transfer + LPT applied per tile: zero resident reference memory, kills the measured 76 B/p IC peak. Panphasia proves the production pattern (MXXL, FLAMINGO; stateless per-cell evaluation); Random123 proves the primitive; nobody has shipped the flat-hash per-tile combination in a cosmology code — sCOLA computes one global field and slices it. [A]

  • Caveat: naive jax.random.split(seed, n_tiles) is not tile-count-invariant; key on absolute mode/cell indices so any tiling yields identical fields.
  • Fourier-space consistency across tiles needs care (k-space noise + per-tile real-space synthesis, or Panphasia-style octree in real space).

Gate: tile-vs-monolithic IC field identity at f64 on a 256³ toy. Effort: S–M.

R2 · Coarse stored LPT reference simple fallback

Ψ1 (and optionally Ψ2) on an n/4 Lagrangian grid in f16 ≈ 0.4 B/p, interpolated. Reference error only inflates the residual it serves; never biases physics. Only needed if S4/COLA frames survive their gates.

R4 · Coarse Lagrangian sheet as state open premise

Keep the displacement field on a coarser-than-particle Lagrangian grid; interpolate/tessellate to deposit mass. The literature has no cosmological accuracy-vs-coarseness number: the 4×-fewer-DOF result (Hahn & Angulo) is an idealized mixing test, and sheet complexity explodes at virialization (ColDICE). Naturally suited to the quasi-linear regime; entirely unpriced. [A]

Gate: paint P(k)/bispectrum from an n/2 and n/4 sheet of a stored trajectory (an afternoon with existing npz data); kill if percent-level fails at n/2. Effort: S to gate, L to adopt.

4.3 Mesh & force solve

M1 · Minimal-buffer monolithic: FD-of-φ promising

One in-place r2c → multiply Green’s function → one inverse transform of φ → finite-difference gradients at gather time. 2 transforms instead of 4; ~8–12 B/cell incl. reusable cuFFT workspace (cufftSetWorkArea verified; default workspace size undocumented — measure). Hockney–Eastwood-standard kernel matching; a 2026 JAX-multigrid paper reports no significant accuracy edge for spectral ik over FD in their tests. [A]

Gate: force-error ladder vs the spectral path on the existing probe; D-013-class parity must hold. Effort: S.

M3 · Two-level mesh: global coarse + fine tiles the unlock

PMFAST (2005): global mesh 4× coarser + fine mesh “only the tiles being worked on”, polynomial force matching — verified. CUBE2 runs a three-level version in production with 10–30% measured buffer overhead. Fine-mesh residency drops from ρ·N to O(tile): the mesh term leaves the budget, and ρ>1 (fine forces) becomes affordable. [V]

  • Cons: force-split error must be re-validated at our F1 bar (CUBE2’s published validation is ~5% P(k) class); buffer replication cost; more code.

Gate: G5 — two-level vs monolithic force error at 256³, D-013 metrics. Effort: M.

M4 · Multigrid Poisson watch

8/7·N³ hierarchy, no FFT workspace, stencil-local (tile- and streaming-friendly, no global transpose). JAX-native precedent posted 2026-07-13 (arXiv:2607.10983) claims 1.5–1.6× over FFT at 8–32 GPUs. Single-GPU FFT is probably still fine; revisit if cuFFT workspace or tiling friction bites. [A]

M5 · f16/bf16 FFT force dead at F1

tcFFT-class relative error ~1.7% (1D/2D; no 3D data) and pow2-only constraints: orders above our force-error budget. Keep half precision for bulk storage only. [A]

M6 · Deterministic int32-mesh paint keep everywhere

Bit-stable on CUDA by associativity and measured faster than f32 atomics (0.79–0.85×). Reproducible mocks across reruns for free. This is settled in-house engineering; every architecture below assumes it. [M]

4.4 Execution & residency

E2 · GH200 coherent streaming promising

State in 116 GB LPDDR, mesh + active tiles in 96 GB HBM. Measured C2C: 375 GB/s H2D / 297 D2H; ATS reportedly degrades least on irregular access (CIC-like). A 2048³ state sweep at 9 B/p is ~0.5 s/step of traffic. Whether JAX/XLA can use the coherent path is undocumented — the official story is explicit pinned_host offload. That single unknown is gate G4. [A]

Gate: G4 on a Vista node. Effort: S to gate.

E3 · Host/NVMe out-of-core (Abacus-on-a-node) hero tier

S3 H100 nodes: 1 TB DDR5 + 3.5 TB NVMe behind 4 GPUs. Abacus proved slab streaming at 1300 MB/s sufficed for 4096³ on 2018 CPUs; our GPU compute rate is higher, so accept GPU idle (memory-first) — their own reason for abandoning disk mode. No GDS-for-sim-state precedent exists (open lane). [A]

Gate: staging-overlap microbench on one S3 node. Effort: M.

E4 · Sequential independent tiles (sCOLA) conditional

Tiles evolve with zero communication after init in a shared 2LPT frame: resident memory = one tile (~0.4–2 GB) for any box size, at r ≈ 3.2× redundant compute (buffer ≥ 25 Mpc/h, tile ≥ 50 Mpc/h, verified). Error is seam-localized; large scales ride the LPT frame. Nobody has ever published its bispectrum error — the fNL-relevant statistic. ~11 citations, no production adoption. [V]

Gate: G3 — tiled vs monolithic at 256³–512³ incl. squeezed bispectrum. Kill if squeezed-B error > the mock covariance budget. Effort: M.

E5 · CPU-node factories cheap-SU lane

256 Vista GG nodes at 237 GB / 850 GiB/s; 560 SPR nodes at 128 GB HBM2e; Frontera large-mem 2.1 TB. JAX-CPU runs the same code. PM is bandwidth-bound, and GG bandwidth is ~2× a desktop GPU’s. Worth pricing once the code exists; zero design cost now.

4.5 Framework

X1 · Disciplined pure JAX fragile ceiling

Donation is conditional with silent copy fallback (OpenXLA docs); grad-of-scan memory grows with steps; remat regressed across point releases; one indexing pattern doubled a peak (jax issues #3186 / #26639 / #27748). Our measured 138 B/p forward is what discipline alone bought. Exception: under E4 tiling the XLA tax multiplies the tile, not the box — plain JAX becomes fine. [A] [M]

X2 · JAX + custom kernels the target

Pallas paint/gather (the scatter primitive gap is documented; a hand atomic-add kernel is the workaround — unbenchmarked, which is exactly gate G1) + cuFFT via jax.ffi + preallocated arenas. Keeps jax.grad composability per-kernel via custom_vjp. Target: forward ~28–36 B/p monolithic, ~12–16 tiled. [A]

Gate: G1 microbench on deneb. Effort: M–L.

X3 · CUDA/C++ core last resort

The floor is certain (CUBE’s 9.84 B/p exists in Fortran+MPI), but it forfeits autodiff, the JAX ecosystem, and most inexor code reuse. Take only if G1 shows Pallas/ffi cannot reach within ~2× of the hand-managed floor.

4.6 Differentiability overlay (optional)

D2 · f32 backsolve replay honest default

Measured: f32 replay gradient error ~4e-5, flat in K. The fidelity argument against float replay is dead; use it and keep the int path for the primal only. [M]

D4 · Tile-chunked custom VJPs the real attack

The ~430 B/p adjoint transient is XLA VJP scratch; hand-managed reverse sweeps bound it by tile size. Adjoint-through-spatial-tiles is unpublished (sCOLA is forward-only, grep-verified). Checkpoint compression has receipts (ZFP CF≤16 negligible gradient impact). Cotangent precision floor: ~10 significand bits (MITgcm) — fp16 marginal, bf16 risky. Target: adjoint ≤ 2× forward ≈ 60–100 B/p ⇒ 1024³ differentiable on one GPU (today: 512³ max). [A] [M]

Rule: build only when a workflow names itself (bayes-lss field-level fNL?). Effort: L.

D3 · Exact int replay shelved logic stands

Bitwise-reproducible gradients remain the one thing float replay cannot promise. The retrospective’s condition still binds: name the workflow that pays 2× wall and ~100× accuracy for it, or leave it shelved. The machinery survives in the repo either way.

4.7 Scope & ML alternatives

P1 · Pure surrogates (SR / displacement emulators) not certifiable for fNL

Every bispectrum validation in this literature sits at deeply nonlinear k (6–8 h/Mpc), never the primordial-signal regime; PNG generalization was tested only per-particle; diffusion variants drift the mean density and fail OOD cosmologies; one-halo terms suppressed 30–50%. Telling: the Quijote-PNG field-level inference paper used real simulators despite the emulator’s author being a co-author. Revisit only with a dedicated validation campaign. [A]

P2 · COCA-style residual correction compute lever, tiling hook

ML frame + n_f≈8 real force evaluations gives <1% P(k) and near-perfect squeezed-isosceles bispectrum on a 128 Mpc/h box, robust to deliberate cosmology misspecification, trained on 100 sims. It saves force evaluations, not resident bytes — and its own path to volume (sCOLA tiling) is proposed, unbuilt. Our A3 tiling infrastructure would be that extension: a natural collaboration/paper hook, not a dependency. [A]

P3/P4 · Output-side: bias emulation + on-the-fly analysis adopt at output

BACCO-style hybrid Lagrangian bias on displacement fields is production-proven on BOSS data (1–2% galaxy P(k) to k~0.6): a mock factory can emit biased-tracer fields without halo finding. On-the-fly P(k)/lightcone accumulation (PKDGRAV3’s 2-trillion-particle run, HACC in-situ) kills snapshot I/O. Neither changes resident B/p; both change what a “mock factory” node needs to keep. [A]

Section 6

Candidate architectures

A1 · One-GPU Flagship lowest risk

Compose: S1/S2 + M1 + M6 + E1 + X2. Target: 28–36 B/p all-in.

Monolithic PM rebuilt on custom paint/gather + in-place FFT. Reuses most of inexor’s src verbatim. 1024³ in 30–39 GB (fits an A100-40; comfortable on 80–96 GB). 2048³ needs node tiers.

Gates: G1. Effort: M. Paper: thin alone; feeds P-A.

A2 · Mock Factory primary recommendation

Compose: S2/S3 + M3 + M6 + R1 + E1/E2 + X2 (+S7 at rest). Target: 10–16 B/p all-in.

Two-level PM in the PMFAST/CUBE2 lineage with compressed state and on-demand tile ICs. 2048³ = 86–137 GB: one Vista GH node (state in LPDDR, sweep ≈0.5 s/step over C2C). 4096³ = 0.7–1.1 TB: host-resident on one S3 H100 node (≈27 s/step PCIe sweep; K=40 in under an hour of traffic). Fine-mesh ρ>1 becomes affordable, which is also what lets the F2 codec tier meet fNL-band fidelity.

Gates: G1, G2c, G5 (+G4 for the GH claim). Effort: L. Paper P-B: “Gpc-grade PM mocks on one node” + the fNL-statistics tiling validation the literature never did.

A3 · Any-GPU Tile Factory lowest effort

Compose: E4 + S1 + M6 + R1 + X1 (plain JAX!). Resident: ~0.4–2 GB for any N.

sCOLA-style independent tiles run sequentially; the XLA tax applies per tile, so no custom kernels needed. 2048³-class overnight on deneb’s 6 GB 3050 (≈4–7 h at r=3.2, rough estimate), or cheaply across GG CPU nodes. Everything hangs on the seam question.

Gates: G3 (squeezed bispectrum — unmeasured in the entire literature), R1 identity check. Effort: M. Paper P-C: the G3 study stands alone whichever way it lands.

A4 · Hero Run A2 extension

Compose: A2 + E3 (+S7 packing on the streamed tier). Target: 4096³ on one S3 H100 node.

Host DDR5 (1 TB) as the state tier, NVMe (3.5 TB) for packed spill and snapshots. GPU idles between slabs; memory-first accepts that, and nobody has shipped GDS-streamed simulation state (open lane). Only worth building after A2 exists.

Gates: staging-overlap bench; Abacus’s disk-vs-compute-rate caution re-priced on our step times. Effort: M on top of A2.

A5 · Differentiable Sequel wait for a named workflow

Compose: A1/A2 + D2 + D4 (+CAMS/ZFP checkpoints at large K). Target: adjoint ≤ 2× forward.

Section 7

The gate week — price every premise before building anything

Each gate is cheap, decisive, and maps to a kill trigger. This is the inexor lesson applied in advance: the comparison target’s number, in the exact quantity, on the real hardware, before a line of package code.

  1. G1 — custom-kernel floor (deneb, 1–2 days): Pallas atomic-add CIC paint + gather microbench, chunked, vs the XLA-native path; measure peak B/p and wall. Kill A1/A2’s X2 route if >2× the hand-managed estimate; fall back to X3 (CUDA core) or A3 (tiles-in-JAX).
  2. G2c — accumulated codec gate (laptop/deneb, 1 day): plug S2/S3 codecs into the existing m1_quant_gate; the one-shot 3.1e-5 must hold ≤5e-4 accumulated with the mesh-floor invariant. Kill S3 at F1 if it needs >9 B/p to pass; S1 remains the fallback (validated).
  3. G3 — tile seam study (deneb, 2–3 days): 256³–512³ monolithic vs sCOLA-tiled at our config; P(k), cross-r, and squeezed bispectrum. Kill A3 if squeezed-B bias exceeds the mock covariance budget at fNL scales; result publishable either way (P-C).
  4. G4 — GH200 coherent-path reality (1 Vista job): can XLA/JAX touch LPDDR-resident arrays at C2C speeds (ATS) or only via explicit pinned_host staging; measure GB/s through a real paint step at >96 GB working set. Downgrades A2’s 2048³-on-one-GH claim to explicit staging if negative (slower, still viable).
  5. G5 — two-level force split (deneb, 2–3 days): PMFAST-pattern coarse+tile force vs monolithic at 256³, D-013 metrics. Kill M3 (and A2’s shape) if matched-kernel error cannot sit below the D-014 band; A1 remains.
  6. R1 identity check (laptop, hours): tile-generated ICs bitwise/roundoff-identical to monolithic at 256³ f64 under re-tiling. Kill on-demand ICs if k-space consistency cannot be made tiling-invariant cheaply.

Then a decision session with JC: pick one architecture, write its M0 as a hard go/no-go (roadmap convention carries over), and only then open the repo. Total gate cost: about a week of deneb/laptop time plus one Vista job.
